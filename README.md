# 📝 Custom Note App (Frontend Only)

A simple note-taking app built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript** with **localStorage** for client-side persistence. No backend or API used.

---

## 🚀 Live Demo

🔗 [Live Site on Netlify](funny-taffy-0f8a4b.netlify.app)

---

## 📦 Features

- Add and save notes
- View notes list with title and preview
- Data persisted in browser's localStorage
- Navigation between "Add Note" and "View Notes"
- Error handling for localStorage failure
- Saving spinner for UX feedback

---

## 🛠️ Tech Stack

- **HTML** – Structure
- **Bootstrap 5** – Responsive UI components
- **Plain CSS** – Minor custom styles
- **Vanilla JavaScript** – Logic and data handling
- **localStorage** – Client-side note persistence
